# BioGraph - Análisis de Redes de Interacción Proteína-Proteína

# Descripción
Aplicación en Java que modela redes de interacción proteína-proteína (PPI) mediante grafos, permitiendo detectar complejos proteicos (BFS), identificar proteínas hub (centralidad de grado) y calcular rutas más cortas entre proteínas (Dijkstra).
